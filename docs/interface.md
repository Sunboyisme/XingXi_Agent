# XiaoXi的奶油杏界面

## 设置与工具管理（2026-10-17）

「连接与设置」内分为连接、工具、记忆三个页签，切换时保留未保存的连接表单。完整的记忆管理移入记忆页签，侧栏不再单独列出记忆；候选提示移到设置入口和记忆页签，原有记忆快捷操作直接打开对应区域。

工具页集中显示内置工具与 MCP 服务，提供搜索、单项开关、服务编辑、测试、启停与删除。新增服务和新发现工具默认关闭。表单和 JSON 导入沿用现有 Dialog 与控件，测试及错误按操作显示。聊天工具菜单使用同一个目录，管理入口直达工具页签；调用记录显示来源服务和耗时。

采用用户于 2026-10-16 选定的「奶油杏」方案：大圆角、暖奶油底色、杏桃色强调和圆润的小精灵形象。基础结构在 `src/style.css`，当前主题在 `src/styles/cream.css`，由 `src/main.tsx` 按此顺序加载，其后再叠加 `src/styles/` 下的版本覆盖层。

## 交互

- 输入框：Enter 发送，Shift + Enter 换行；中文输入法确认候选词时不触发发送。上传中或内容为空时禁用发送，生成时显示停止按钮。
- 新对话保留文字和附件草稿，不因日期更新或侧栏展开／收起而重建输入组件。模型和思考选择按聊天保存在本机，离开页面后返回恢复；新聊天从当前默认开始。
- 普通回答中断后保留已经展示的正文，标明未完成并可复制、重新生成；重试使用当前模型选择和当前连接配置。消息接收成功与列表刷新分别反馈，刷新失败不改变提交结果。
- 对话输入区随内容和窗口宽度调整高度，最高 180px，长文本通过内部滚动查看；首尾保留文字内边距，工具栏独立占位，不覆盖最后一行。已连接模型时，新对话占位文字为“今天有什么灵感，随心输入”，已有聊天为“输入消息…”。
- 输入框旁的 MCP 菜单只显示已配置的 MCP 工具，可直接开关；内置工具仍由 Agent 自动调用。模型菜单可在已配置连接的模型间切换，思考按钮按模型能力启用或禁用。
- 2026-10-30 将上下文用量圆环移到左侧回答方式控件的“对话”右侧，模型菜单不再包裹用量组件；保留按会话与模型隔离的统计、整理中提示和键盘／悬停 Hint。思考强度与上下文窗口子菜单移除底部“使用模型默认”操作及其分隔线，保留具体档位、新对话继承配置和已保存的会话选项。
- MCP、技能菜单仅保留功能标题，移除“全局生效”和“影响所有对话的后续调用”常驻说明，原有开关范围保持不变；支持方向键选择、Enter/空格切换、Esc 关闭并返回入口。
- 模型设置使用连接列表与添加／编辑弹窗，支持同一服务商的多套独立连接；主页面统一选择默认模型。详细约定见 [模型连接](model-connections.md)。
- 2026-10-30 思考设置使用右侧对齐的主题开关及开启／关闭文字；可用强度以等宽、多选且带勾选标记的档位展示，默认强度独立使用主题选择框。移除强度区域的嵌套卡片与横向标签留白，窄窗口分行；至少保留一档，删除当前默认档位后回退到服务商默认。
- 桌面问答的发送请求明确使用对话模式，未手动选择模型时也携带当前默认连接与模型，不再因省略配置回退到智能体模式；继续继承模型的思考开关与默认强度。主聊天已有的回答方式选择保持原行为。
- 桌面问答展示模型实际返回的思考片段，生成中展开、进入正文后收起，支持手动展开及滚动；重新打开已有任务时恢复思考记录。共用思考入口只保留文字与展开／收起箭头，不放装饰图标，采用四角一致的圆角和键盘焦点提示，截图背景下保持清晰对比，浮动聊天沿用当前主题。用户不喜欢脑形图标，思考过程及其他界面不使用脑形图标。长回答在底部自动跟随，向上滚动阅读时暂停跟随。
- 桌面问答顶部的主窗口入口使用窗口图标与“继续对话”文字；没有关联对话时显示“主窗口”。点击会打开对应内容，收起置顶问答及截图冻结层后聚焦主窗口，后台回答继续运行；失败通过现有错误区反馈，悬浮说明继续使用支持悬停与键盘聚焦的主题 Hint。本轮实际桌面效果仍待用户检查。
- 收起／展开按钮固定在窗口标题栏左侧，两个状态位置一致。头像独立提供悬浮和点击动效。固定的 76px 图标栏负责导航，独立聊天侧栏包含 XiaoXi 标题、新聊天和完整历史列表；窄窗口使用浮层。应用初始页面及每次新建对话默认收起聊天侧栏，可手动展开；不再从旧的侧栏展开偏好覆盖这一默认状态。收起保留草稿，新聊天清空当前输入。主题和侧栏宽度偏好继续保存在本机 localStorage。
- 主窗口使用 40px 自定义标题栏，支持拖动、双击最大化、最小化、最大化／还原及关闭到托盘。启动时按当前显示器工作区与 DPI 缩放，限制首选 1280×800 逻辑尺寸并居中，预留屏幕边距；内容区使用剩余高度，底部不再被 100dvh 重复占位挤出窗口。
- 工具记录使用可展开的圆角卡片，分行展示名称、返回内容和「已返回／待确认／调用失败」状态；失败项使用独立图标及颜色。重新进入对话恢复最近一轮的持久化记录。
- 输入区不常驻显示发送快捷键说明；Enter、Shift+Enter 与中文输入法处理保持原有行为。
- 模型入口打开菜单，显示当前连接并提供「连接与设置」。当前产品只有一个已配置连接；这里不展示不存在的模型选项。
- 菜单支持方向键与 Enter，Esc 关闭并返回触发按钮；弹窗保留 Radix 的焦点约束与键盘操作，并在关闭后恢复焦点。
- 保存与提交期间显示处理状态，失败时显示可读信息。学习状态、记忆确认与提醒完成使用明确文字区分。
- Tab 导航保留按钮、菜单等控件的焦点轮廓；根据用户批注，对话输入框聚焦时不出现外围选中框。减少动态效果的系统设置会关闭过渡与装饰动画。

大圆角及本轮配色是用户确认的项目局部选择。没有修改共享 QinBai 设计系统母版；模型、课程、记忆和提醒继续使用原有接口与数据结构。

头像最终采用用户确认的平面 A 版；此前的印记、小芽和高光立体方案不再用于实际界面。
