# XiaoXi 0.1.7

2026-10-23 根据用户本轮“构建安装包吧”的明确要求，生成 Windows x64 安装包。业务源码基于提交 `e41f197`，版本保持 0.1.7。

## 本次交付范围

- 新对话使用「一句开场」首页：小希形象、简短日期、问候、居中的紧凑磨砂输入框与淡色柔光，默认收起聊天侧栏。
- “理清思路、写点东西、安排今天”替换输入框文字并聚焦末尾；“继续学习”直接打开学习界面，保留聊天草稿和附件。占位文字为“今天有什么灵感，随心输入”。
- 加号菜单保留附件、MCP 和技能入口；MCP／技能菜单精简常驻说明。已有聊天保留悬浮输入、消息避让与滚动优化。
- 包含本版已有的项目概览、聊天归属选择、重命名、拖动归组、本地工作目录选择，以及侧栏、任务短标题、日历恢复默认排序和学习创建信息校验等修改。
- 后端随包封装，包含本版数据库迁移与运行依赖。完整历次修改和各自的验证状态见 [0.1.7 更新记录](../updata/0.1.7/changes.md)。

## 构建与验收范围

- 执行 `pnpm release:windows`，TypeScript／Vite 生产构建、PyInstaller 后端封装、Rust release 编译及 NSIS 安装器生成均完成。
- 安装器文件版本与产品版本均为 0.1.7；交付副本与构建原件的 SHA-256 一致，校验文件已随包保存。
- 沿用当前打包配置，资源来自后端程序、迁移、内置技能及运行依赖，未引入个人数据目录或凭据。
- 本轮未运行自动化测试、模拟检查、原生窗口检查、真实模型或微信收件验收，未运行安装器、替换个人安装目录或操作桌面测试版。构建完成不代表业务及安装升级验收通过。
- 构建保留主 JavaScript chunk 大于 500 kB 的提示；后端封装保留 `httpx2.websockets` 缺少 `wsproto`、部分可选隐藏导入和依赖弃用／beta 提示，详细日志保存在本机。本轮未追加对应功能的运行验收。

待用户验证：安装与覆盖升级、已有数据和连接保留；首页显示与三个开场入口替换输入；“继续学习”导航及返回后的草稿；项目、附件、MCP／技能、学习与日历等实际业务。
