# XiaoXi 0.1.4

0.1.4 增加办公文件处理，并修正桌面界面与交互反馈。2026-10-20 用户明确授权构建 Windows x64 安装包。

## 办公文件

- 支持上传 DOCX、PDF、XLSX、TXT、MD、CSV、JSON，显示解析状态、错误与重试入口。
- 小汐通过当前对话内的文件工具按需读取资料，生成 Word、PDF、Excel 和文本结果文件。
- 结果以文件卡片展示，支持预览、下载和原生「另存为」；PDF 使用实际页面渲染，Word 使用内容预览，表格显示计算缓存值。
- 原件保持不变，读写限定在应用管理的文件范围；暂不开放任意本地文件夹。扫描 PDF 暂不支持 OCR。
- 解析和生成采用有超时、并发、内存及文件大小限制的固定子进程协议。详见 [文件功能](../files.md)。

## 学习与定位

- 对话侧边增加紧凑的定位刻度，悬停显示问题与三行回答摘要，点击跳转到对应对话。
- 练习回答区固定在学习内容下方，支持拖入图片，附件以文件名展示，避免输入区随内容滚动。
- 修正结束重复系列后当天未完成事项仍保留的问题。

## 提醒

- 提醒窗口取消系统标题栏、边框和任务栏按钮，以无边框卡片显示在当前屏幕右下角。
- 保留每个提醒的「10 分钟后再提醒」，并整理多条提醒时的操作层级。

## 计划

- 首页「今日安排」打开当天的待办事项或重复事项，不再直接进入编辑表单。
- 月历不再为每个重复日期铺开同一系列；每天只显示一个重复数量入口，点击后查看当天重复事项。
- 周历采用相同的重复折叠方式。
- 结束重复系列使用独立的确认层，明确「保留系列」「结束系列」以及「只完成本次」的区别。

## 对话

- 修正生成中状态文字被旧版圆点样式压缩成竖排的问题。
- 思考和回答持续增长时自动跟随底部；用户向上翻阅后暂停跟随，回到底部后恢复，并提供「回到最新」入口。
- 输入区浮在对话上方，留白与背景透明，滚动的回答可以从下方露出。
- MCP 旁增加技能入口，保持原有的紧凑按钮外观，可直接查看、启用或关闭技能，并进入技能管理。
- 首页增加解释概念、提炼重点和随意聊天等提示词，重写安排今天和整理文字的自然语言提示；移除提示词前的标签，点击提示词会替换输入框中的旧文字。
- 默认外观改为暖灰棕深色主题，仍可在设置中切换并记住奶油杏浅色。

## 连接

- 模型连接区重新分层：默认模型摘要、服务商连接、模型和密钥状态分区展示。
- 模型配置弹窗按「服务商 → 接口与凭据 → 模型」三步组织，服务商预设改为可点选卡片。
- 服务商预设改用常用、高性价比模型名称；思考支持按服务商与完整模型名识别，并直接显示识别结果。
- 语义记忆检索弹窗重新组织启用开关、接口字段、密钥操作与索引状态；已保存密钥的清除操作收进字段标题行。
- 删除 Embedding 地址下方的多余提示，并将开关说明改为「按语义相似度召回」。

## 技能与记忆

- 技能卡片简介统一显示两行，卡片底部留出清晰操作区，避免「查看技能」与文件状态文字挤在一起。
- 技能详情中的「技能正文」和「文件清单」改为带图标、说明和展开箭头的独立折叠区。
- 记忆卡片默认等高并显示三行摘要，超长内容可展开查看详情。

## 系统菜单

- 托盘菜单增加新建对话、打开今日安排和连接与设置，并移除容易被误解为「暂停提醒」的退出说明。

## 验证范围

- 前端 24 个测试文件、77 项测试通过；后端 218 项测试通过。
- TypeScript、Vite 和 Rust release 构建通过。
- 隔离浏览器验证覆盖上传 Word/PDF、模拟模型按需读取、生成 Word/Excel、预览与下载。
- 打包后的办公子进程验证七种格式生成与读取、中文 PDF 页面渲染及 Excel 公式缓存值。
- NSIS 安装包完整性与版本检查通过，未包含个人数据库、凭据或模拟模型；从安装包解出的后端在隔离目录启动，七种格式上传、解析、原件下载和预览通过。
- 固定复用 `.local-data/preview-runtime` 的原生桌面检查通过，保留已有真实模型连接，确认工具入口与文件预览、原生另存为；未向该目录注入模拟数据。
- 本次打包检查未调用真实模型、未测试微信收件；模拟模型结果不代替这些验收。
