## 本版调整

- 模型连接改为列表与添加／编辑弹窗，同一服务商可添加多套独立名称、地址、密钥和模型配置。
- 提供阿里云百炼、DeepSeek、Kimi、智谱、硅基流动及自定义兼容接口预设，统一选择默认模型。
- 聊天区可切换已配置模型，思考按钮按模型能力开关。图片及思考协议收进模型的能力设置。
- 聊天工具菜单只显示 MCP 工具与开关；内置工具继续由 Agent 自动调用。
- 输入框使用轻量聚焦状态，记忆模式等下拉框统一样式与键盘操作。
- 标题栏加入文件、编辑、视图和帮助菜单；学习、提醒和设置页不再显示聊天侧栏。
- 主窗口按显示器实际工作区、DPI 和外框限制大小；窗口首选 1280×760 逻辑尺寸，正文与弹窗可在窄矮窗口内滚动，底部操作保持可见。
- 关于弹窗移除退出按钮，产品名称统一为 XiaoXi。保留独立聊天侧栏、头像互动及微信卡片分组调整。
