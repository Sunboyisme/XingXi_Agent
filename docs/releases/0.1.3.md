## 本次包含

- [统一计划](../updata/0.1.3/unified-plans.md)：提醒与日历合为「计划」，提供月历、列表两种视图；支持全天、定时、每日／每周／每月重复和多个提醒时间。计划、单次完成与通知状态分别保存；关闭提醒保留计划，知道了只读通知，稍后提醒仅影响本次通知，重复事项区分完成本次与结束系列。聊天使用统一计划工具，迁移关联记录时去重并保留原状态。
- [重复计划展示与编辑](../updata/0.1.3/recurring-plans.md)：月历默认把重复事项汇总为「日常 X 项」，重要日程可始终展开；列表按系列展示每月次数、完成数和下次提醒。重复结束支持永不结束、截止日期（含当天）和重复次数（含首次）；编辑范围包含仅本次、本次及以后、整个系列，单次变化与后续规则保存为附属记录，不另建计划。
- [月历与节日](../updata/0.1.3/month-calendar.md)：保留农历、节气、节日及日期格中的休／班标记，补齐 2027 年除夕等节名；移除周历与顶部节假日跳转、图例。官方调休数据仅覆盖已录入的 2025／2026 年，不推测 2027 年放假安排。
- [聊天首页](../updata/0.1.3/chat-home.md)：固定保留「今日安排＋上次任务」，删除三版选择栏及其他两版的代码、样式和切换逻辑；保留添加安排、整理笔记、继续学习入口，移除标题下说明文字。
- [两套主题](../updata/0.1.3/appearance-themes.md)：原有奶油杏浅色、暖灰棕深色，可在设置的外观页切换并记住选择；聊天内容区移除角色形象，侧边栏等位置保留形象与交互。
- [技能与脚本环境](../skills.md)：支持文件夹／ZIP 和文件拖入；内置 `text-notes` 示例，脚本单独授权；Python、Node.js、PowerShell 和 Bash 在独立设置页管理。
- 保留既有 MCP 配置、网页来源折叠与链接打开、图片／产物、记忆查看和检索配置、数据导入导出及真实模型连接等改进。数据库迁移包含 `0001` 至 `0012`。
