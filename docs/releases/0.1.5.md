# XiaoXi 0.1.5

2026-10-21 更新构建，由用户本轮明确要求生成 Windows x64 安装包，版本号保持 0.1.5。

## 本次交付范围

- 复杂任务自动识别、分步执行、执行中补充要求、停止恢复、成果版本管理及最终交付核对。
- 任务卡位于对应 XiaoXi 回复内，保留名称、状态和成果，展开查看步骤及原因；移除继续／结束按钮和重复的未完成提示，已完成任务收到继续要求时保持完成状态。
- 聊天输入区统一发送／停止按钮：执行中无草稿时停止，有文字或附件时发送；任务补充沿用当前执行，普通回答先停止上一轮再提交新消息。
- 模型连接支持拉取列表、搜索、多选及逐条设置图片输入；多轮记忆整理区分本轮授权与历史用户原文，保留来源、撤销和更新能力。
- 修正任务展开反馈、图片和文件成果布局；区分程序步数上限、限流、请求超时及连接错误，并为后续失败保留诊断元数据。错误横幅可手动关闭。
- 包含计划起止时间联动、聊天图片粘贴、附件预览间距、正式版名称统一及柔光生图等待画布。
- 一并归档此前工作区中的学习内容流式展示、思考展示与滚动、技能菜单布局和主题悬停提示修正。

## 构建与验收范围

本轮安装包使用当前工作区源码构建，封装 Python 后端、数据库迁移及桌面运行依赖，不包含个人数据库和模型凭据。旧的同名交付安装包由构建脚本备份；交付副本与构建输出进行 SHA-256 比对。

本轮未运行自动化测试、模拟检查、原生窗口检查、真实模型或微信收件验收，未运行安装器或替换个人安装目录。构建结果不代表业务与安装升级已验收通过。

待用户验证：安装与覆盖升级、已有数据和连接保留；复杂任务补充／停止／终态及卡片位置；统一发送按钮；模型拉取、历史记忆整理、学习流式内容及文件预览下载。
