# 给小汐添加技能

应用首次初始化会添加 `text-notes` 示例技能，默认启用，脚本仍需单独授权。它将用户提供的内容整理成 Markdown 文件。已有同名技能不会被覆盖；删除后也不会在重启时反复恢复。

技能页支持直接拖入文件夹、ZIP 或包含 SKILL.md 的文件组，拖入后先预览再确认。解释器统一在「设置 → 脚本环境」的独立页面配置；技能页上方的「运行环境」会跳转到该页。

打开「设置 → 技能」，选择包含 `SKILL.md` 的文件夹或 ZIP。预览技能说明和文件清单，再确认导入。每次导入一个技能，最多 500 个文件、20 MB。`SKILL.md` 需要 YAML `name`（英文小写、数字及短横线）和 `description`，正文使用 Markdown；参考资料放 `references/`，脚本放 `scripts/`，素材放 `assets/`。

导入不执行文件，默认停用。开启技能后，小汐根据名称和描述判断任务是否适用，先加载说明，再按需读取参考资料。技能包中的说明不能新增用户授权，也不会绕过工具开关。当前不扫描其他软件的技能目录，不自动下载依赖。

## 脚本授权与运行

在技能详情中单独开启「允许小汐自动运行此技能的脚本」。这代表你信任该技能的代码：脚本以当前 Windows 用户权限运行，可以访问用户有权限访问的文件与网络；工作目录不是安全沙箱。重新导入且内容变化时，会关闭技能并撤销原授权。

支持 `.py`、`.js`、`.mjs`、`.cjs`、`.ps1` 和已安装 Bash 的 `.sh`。设置页可查看运行环境，并填写解释器程序的绝对路径。安装版自带的后端不作为第三方 Python 解释器；需要另行安装 Python 及技能依赖。

小汐通过 `run_skill_script(skill_id, path, arguments)` 执行，`arguments` 是字符串数组，不拼接终端命令。只能选择已授权技能 `scripts/` 下的脚本。每个聊天任务有独立目录，同一任务中的多个步骤可以复用文件。脚本默认不继承小汐的模型密钥或微信凭据。

单次最多 60 秒，整轮任务也有超时限制。聊天停止、技能停用、撤销脚本授权或点击「停止脚本」会终止相关进程树。外部操作已经发出时，停止或超时不代表撤销成功，不会自动重试。

## 输出与示例

文件产物写到环境变量 `XIAOXI_OUTPUT_DIR` 指向的 `outputs/`。小汐会持久化最多 30 个、单文件不超过 20 MB 的产物；图片另有 10 MB 和尺寸限制。回答下方可预览图片或保存文件；桌面版保存到当前数据目录的 `exports/` 并打开该目录，浏览器测试环境使用下载。工具调用记录可展开查看脚本退出码、标准输出和错误输出。

示例位于 `docs/examples/text-notes/`：导入这个目录，启用技能并授权脚本，设置 Python 后，对小汐说「用 text-notes 把下面的内容整理成笔记」。示例不联网，不依赖第三方 Python 包。技能选择和步骤执行质量取决于所配置模型。

技能包、启用状态、执行授权和解释器配置属于当前数据空间的本机配置，不随个人数据导出或导入替换。已生成的产物随个人数据导出。
