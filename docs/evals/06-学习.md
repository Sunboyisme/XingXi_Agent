# 121—134：学习

覆盖学习目标的创建（聊天与学习页访谈）、进度查询、聊天中继续学习、讲解与练习、批改与补救、复习与复习提醒、会话接续。规则依据 [docs/learning-sessions.md](../learning-sessions.md)。

**说明：** 教学内容由模型生成，检查重点是流程是否正确、反馈是否有依据，而不是文字与示例完全一致。

---

## 创建与查询

### 121 在聊天中创建学习目标

```text
我想系统学习 Python 数据分析，零基础，目标是能用 pandas 分析自己的记账表。每周大概能学 3 小时。
```

- [ ] 调用 `create_learning_goal`，学习页出现新目标与路线（模块、知识点、前置关系）
- [ ] 路线从 Python 基础开始，到 pandas 读取与汇总记账数据，符合零基础
- [ ] 没有自动往日历写入学习计划

### 122 学习页引导访谈创建目标

**操作：** 「学习 → 新的学习方向」，按页面引导依次回答（每轮只回答一个问题）：

```text
我想学前端，做一个个人作品集网站。
```

```text
会一点 HTML，CSS 只会改颜色，JavaScript 没学过。
```

```text
每周 4 小时，希望 12 月底前上线。
```

- [ ] 每轮只追问一个核心问题
- [ ] 生成的摘要可编辑；改为“希望 1 月底前上线”后再确认
- [ ] 确认后才建立目标与路线；点击重试不重复创建
- [ ] 中途离开页面再回来，访谈草稿可恢复

### 123 查询学习进度

**前置：** 已有 121、122 两个目标。

```text
我现在有哪些学习目标？各自学到哪了？
```

- [ ] 调用 `learning_goals`，列出两个目标与真实进度
- [ ] 不编造已完成的知识点

## 聊天中继续学习

### 124 多个目标时继续学习

```text
继续学习
```

- [ ] 出现接续卡，列出可选目标让用户选择
- [ ] 点选后进入对应目标的学习界面，位置为上次的知识点

### 125 指名继续与否定表达

**新聊天依次发送：**

```text
继续学 Python 数据分析
```

```text
我不想继续学习了，帮我查下明天天气。
```

- [ ] 第一条直接给出 Python 数据分析的接续卡
- [ ] 第二条**不**出现接续卡，正常查询天气（地点不明时询问城市）

## 讲解、练习与批改

### 126 知识点讲解与练习

**前置：** 在任意聊天先发送「请记住：我学 Python 时希望先给一段能直接运行的小代码，再用最多三句话解释。」

**操作：** 在 Python 数据分析目标中选择第一个知识点（如“变量与数据类型”），开始学习。

- [ ] 给出讲解、示例与一道练习
- [ ] 评分标准**不**显示在正文、流式内容或回看中
- [ ] 讲解遵循上面的学习偏好：先代码，再不超过三句的解释

### 127 正确作答通过

**操作：** 针对练习认真作答（用文字或代码），提交。

- [ ] 判定通过，反馈指出答对的依据
- [ ] 知识点进度更新为已掌握／练习通过

### 128 错误作答与补救题

**操作：** 在下一个知识点故意给出错误答案，例如把列表索引从 1 开始，提交。

- [ ] 判定未通过，反馈包含：**参考答案**、**一道更简单的新题**、新题的检查标准
- [ ] 给出参考答案不被算作通过

### 129 追问后按新题批改

**接 128：**

```text
为什么 Python 的索引从 0 开始？
```

**然后针对新题作答并提交。**

- [ ] 追问得到解释，当前题目仍是新题，没有被替换
- [ ] 提交后按**新题**批改，不再追讨旧题

### 130 图片作答

**操作：** 把一段代码在编辑器中截图，作为练习作答上传提交（模型需支持图片）。

- [ ] 能识别截图中的代码并据此批改
- [ ] 若模型不支持图片，明确提示而不是凭空判定

## 复习、提醒与接续

### 131 复习一题

**前置：** 至少有一个已学但未掌握的知识点（128）。

**操作：** 在学习界面点「复习」。

- [ ] 一次只出一道题，优先未掌握内容
- [ ] 复习作答与反馈单独记录，不覆盖原课程与原练习

### 132 安排复习提醒

**操作：** 在学习界面顶部点「复习提醒」，或在聊天中发送：

```text
明天晚上 8 点提醒我复习 Python 列表索引。
```

- [ ] 生成一条明天 20:00 的提醒，到点弹出
- [ ] 请求进行中连续点击不会重复创建

### 133 草稿与会话接续

**操作：** 在练习输入框写一半答案，切换到聊天页，再从托盘完全退出 XiaoXi 并重新打开，回到学习。

- [ ] 半成品草稿仍在
- [ ] 重新打开后**不会**自动请求模型
- [ ] 学习记录列表显示本次会话，可查看“对话记录／本次概况”

### 134 结束学习与关闭窗口

**操作：** 在讲解生成中点击「结束学习」；另开一次学习后直接关闭主窗口（隐藏到托盘）。

- [ ] 结束学习停止当前生成并保存会话
- [ ] 关闭主窗口后，未结束的会话被结束、草稿保留；最小化则不结束学习
