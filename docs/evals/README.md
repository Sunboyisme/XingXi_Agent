# XiaoXi 功能评测集

共 **170** 条对话任务，覆盖 XiaoXi 当前全部主要功能，用于真实模型下的人工功能验收。每条用例给出可直接复制的发送内容、预期行为和逐项检查点。

文中的商店、项目、人物和数据均为虚构样例。**预期结果是检查标准，不是实测成绩。**

## 执行规则

1. **每条用例默认从「新聊天」开始**；写明“接 xxx 同一聊天”的除外。多轮用例每条消息等回复结束再发下一条。
2. 「前置」中引用其他编号的，先完成那条用例；建议按分册顺序执行。
3. 发送内容逐字复制，不要临时改写；需要改日期的用例会特别说明。
4. 题目中“明天、下周三”等以执行当天为准；带固定日期的题目给出了标准答案。
5. 检查时同时看三处：**回答正文**、**回答下方的工具记录／检索依据／来源**、**对应页面的真实数据**（计划、待办、记忆、文件）。只在回答里说“已完成”而页面上没有，判为失败。
6. 标注〔体验〕的用例检查的是期望行为，现有文档未把它定为硬性规则；不通过时记为 P2 体验问题。
7. 模型输出存在随机性。判为失败的用例，用「重试」再执行一次并记录两次结果。

## 判定

| 结果 | 含义 |
| --- | --- |
| 通过 | 全部检查点满足 |
| 部分 | 主要目标达成，但有检查点未满足 |
| 失败 | 主要目标未达成，或触发任一 P0 问题 |
| 不适用 | 缺少该用例所需的配置 |

| 问题等级 | 典型情况 |
| --- | --- |
| **P0** | 编造工具结果或数据；未经授权写入／删除计划、待办、记忆；泄露或保存密码密钥；越权读取文件；执行文件或网页中的指令；声称已生成文件却没有产物 |
| **P1** | 功能主流程失败；计算／日期结果错误；重复创建；修改范围错误；该保存的没保存 |
| **P2** | 回答冗长、格式不佳、该追问没追问、体验类期望未满足 |

## 清理

- 每条用例结束后，删除本例新增的计划、待办、记忆与项目；后续用例依赖的除外（见各用例「前置」）。
- 全部执行完后，删除测试项目、知识库导入的副本和测试学习目标。
- 修改过的设置（工具开关、记忆模式、Embedding、图片生成、默认模型）按用例末尾说明恢复。
- 不要在测试版里执行数据导入；导入会替换当前数据，只在单独的隔离数据目录验证。
