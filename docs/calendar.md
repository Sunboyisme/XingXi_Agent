# 计划

侧边栏只保留「计划」入口。日历（月历）和列表查看同一份事项；列表按月份查看进行中、已完成或全部记录，每个重复系列只显示一行，点击进入本月记录完成或编辑某次事项。统计不包含月历补齐的跨月日期。右上角铃铛查看已经触发的通知，提醒不再有单独的管理页。

重复事项默认在日期格中汇总为「日常 X 项」，点击查看当天的具体时间与完成状态。单次事项优先占用日期格的展示位置；重要会议等重复计划可在编辑时将「月历显示」设为「始终展开显示」。普通事项显示不下时通过「还有几项」查看。周历、顶部月周切换、节假日来源跳转和图例已移除。

事项支持标题、备注、全天、定时、每天／每周／每月重复及自定义间隔。界面显示设置中的时区，默认北京时间。全天按日期保存，结束日期在界面中包含当天；接口使用不包含结束日期的范围。定时事项以 UTC 保存。重复安排保留当地钟点，月末安排按原始日期计算：1 月 31 日 → 2 月末 → 3 月 31 日。

重复结束可选「永不结束」「截止日期」「重复次数」。截止日期包含当天，次数包含首次；截止条件限制事项的发生次数和日期，同步约束后续提醒。某次提前或延后的提醒仍属于该次事项。

对小汐说「帮我安排明天的读书计划」或「添加周五下午三点到四点的会议」，小汐可以查询已有安排、生成日程并直接保存。只讨论建议时不写入；没有具体时间的单项事项默认为全天，明确要求小汐分配时间时可以由模型安排时段。批量规划整体提交，同一条用户消息重试不重复添加。

提醒默认关闭。勾选「提醒我」后可以选择一个或多个日期与时间，最多 10 个。提醒时间以相对每次计划开始的本地分钟偏移保存，可提前或延后；重复计划沿用这些偏移。

| 操作 | 结果 |
| --- | --- |
| 完成事项 | 日历与列表同步完成，取消该次尚未处理的通知 |
| 完成本次 | 仅完成所选的这次重复事项，保留后续安排 |
| 取消本次 | 仅取消所选这次重复事项及其通知、提醒，保留其他日期；日历显示已取消 |
| 恢复本次 | 恢复已完成或已取消的这一次，保留该次原有改期与备注 |
| 结束整个系列 | 保留完成记录，停止整个系列的后续安排与提醒 |
| 关闭「提醒我」 | 保留计划，停止提醒 |
| 通知「知道了」 | 仅标记通知已读，不完成事项 |
| 提醒弹窗「×」 | 仅关闭窗口，通知仍保持未读 |
| 通知「10 分钟后提醒」 | 仅延后这条通知，不改变计划、其他提醒或下次重复时间 |

打开具体重复事项时默认「仅本次」，也可选择「本次及以后」或「整个系列」。仅本次调整保留原发生编号，改期后仍可完成、恢复；同一系列的两个事项不能改到完全相同的开始时间。本次及以后从所选日期开始使用新规则，之前的安排与完成记录保留；选择次数时表示从这次起的次数。整个系列修改基础规则，保留单次调整和完成记录；仅改名、关闭提醒或改变显示方式不抹掉已设置的后续时段变化。完成按钮明确标明「完成本次」，结束系列前需要确认。

聊天继续只暴露统一计划工具。创建可使用 `repeat_until`（含当天）或 `repeat_count`（含首次），二选一；`calendar_display` 为 `summary` 或 `always`。更新使用 `scope=this/future/series`；前两种须传查询得到的 `occurrence_start`，不根据修改后的开始时间猜编号。多个提醒属于同一计划，同一条用户消息的创建重试复用原结果。

月历空白日期双击可添加计划。2025、2026 年放假及补班使用国务院正式通知的固定数据，普通周末不额外标记，其他年份不推测调休日期。来源：[2025 年安排](https://www.gov.cn/zhengce/zhengceku/202411/content_6986383.htm)、[2026 年安排](https://www.gov.cn/zhengce/content/202511/content_7047090.htm)。来源保留在文档中，界面不再显示跳转入口。

桌面提醒需要电脑开机并运行小汐；微信提醒还需要绑定微信并开启对应选项。恢复运行后对遗漏的重复提醒补充一次提示并进入下次安排，不逐条补发历史通知。服务器部署尚未实现，电脑关机后本机计划不会继续执行。

月历日期格显示农历、节气和主要节日名称，节日优先显示，悬停可查看完整农历与节气。除夕、春节、元宵、端午、七夕、中秋、重阳、腊八和元旦、劳动节、国庆等节名独立于年度调休表计算，未来年份也能显示；「休／班」仅根据已有正式安排标记。计算使用 lunar-typescript，本地离线运行。2027 年除夕为 2 月 5 日、腊月廿九，次日为春节；除夕取农历年的最后一天，不固定写成腊月三十。日期样本与[2026 年对照表](https://www.hko.gov.hk/tc/gts/time/calendar/pdf/files/2026.pdf)、[2027 年对照表](https://www.hko.gov.hk/tc/gts/time/calendar/pdf/files/2027.pdf)核对。
