# 学习接续与学习会话

XiaoXi 保持个人助手定位；学习接续入口位于学习界面，聊天首页不增加学习卡片。

选择学习目标后直接进入知识点与学习对话。顶部只保留目标设置、学习记录和已有会话的暂停／结束入口，移除接续大卡片与分钟数选择。开始知识点或提交时自动建立／接续会话，查看目标、会话历史或重新打开窗口不会自动请求模型。已有会话保存的时间信息仍保留。

会话保存知识点、课程、提交、反馈、卡点、下一步和文字／已上传图片草稿。暂停、结束本次学习与知识点练习通过分别记录。返回其他页面或重启后可恢复；未完成的模型请求不会在重启后自动重发。

同一目标最多有一个未结束会话。切换知识点保留原位置的草稿与提交；结束的会话可以查看，新学习从目标重新开始。原有目标和课程首次接续时建立会话，不生成虚构的过去学习时间或活动。

草稿即时缓存在当前设备，并防抖保存到会话。保存失败会明确提示；上传尚未完成的文件不计作已保存附件。旧版知识点草稿在接续时迁移，只有确认服务端保存后才清理旧缓存。

普通聊天中说“继续学习”会给出接续卡，多个目标时选择一个，再进入学习界面。卡片对应记录失效时可打开学习列表。普通聊天中的半成品输入继续保留。

学习目标增加可选的具体成果、每周可用分钟数与目标日期。本轮只保存这些安排，不自动写入日历，不重新生成已有课程，也不将代做成果记作掌握证据。

2026-10-24 最终调整：新建／编辑目标使用独立页内表单，可选成果与排期直接分区展示，目标日期复用主题日期选择器。练习以用户／XiaoXi 对话展示，默认显示最近六轮，用“加载更早的对话”每次增加六轮；已读讲解与反馈依据通过主题按钮进入详情窗口，不使用三角折叠项。复习提醒移到顶部工具区，并防止请求进行中重复创建。

学习记录采用时间倒序的紧凑列表，默认打开最近一次。左侧只显示时间、状态和知识点，右侧通过“对话记录／本次概况”标签查看内容；列表与正文独立滚动，窄窗口改横向记录列表。读取失败可重新读取，不更改原学习记录。

练习未通过时，结构化反馈必须包含参考答案、一道更简单的新题及新题标准。新题与标准保存在原有反馈 JSON 中，不覆盖最初课程、不改写历史；后续追问保留当前题，下一次作答按当前新题批改，不再追补旧题，也不把给出参考答案当作通过。旧课程下一次提交开始采用此规则。

上述为实现行为，真实教学质量、草稿恢复、课程接续与模型兼容性仍待用户验证；本轮未运行测试、模型调用或构建。


2026-10-24 本轮截图修正（待用户验收）：目标表单改为“学习方向／按你的节奏”两栏，窄窗口顺排；修正共享创建页标题选择器误用到内部区块造成的过量留白。入门默认采用主题选项按钮，时间输入附带单位与字段内错误说明。

练习和检查标准中的列表按数字序号展示；旧课程只调整列表渲染，不重写保存正文。新教学与新题的生成指令要求每项回答独立编号。提示改为思路引导行和“查看提示”按钮，完整提示在主题详情窗口按序列出。


## 0.1.8 当前交互（2026-10-25，用户验收）

新建学习目标改为页内引导对话，每轮补充一个核心问题；摘要可编辑，具体成果与时间安排可选，确认后才建立目标与路线。访谈、草稿和生成失败状态可恢复，重试不重复创建目标。

课程讲解与原练习保留在学习对话中，评分标准只供后端判断，不显示在正文、回看或流式内容。输入框常驻并随内容增高，背景沿用聊天磨砂效果，聚焦时不增加边框；上传在左、发送在右。完成本章位于顶部，删除底部章节说明栏；看过讲解即可继续，未掌握内容保留复习。

复习根据当前目标的真实讲解、作答和反馈一次安排一题，优先未掌握内容。复习独立记录来源、题目、草稿、作答与反馈，不覆盖原课程；有充分证据时更新掌握状态。复习与复习提醒分别保留。

标题栏控制课程目录，顶部进度仅显示已学章节。结束学习停止当前生成并保存会话；关闭主窗口时保存草稿、停止学习生成、结束全部未结束会话后隐藏到托盘。最小化不结束学习。

本轮后续验收由用户负责，助手不再默认代为验收；用户明确确认通过前不构建安装包。
