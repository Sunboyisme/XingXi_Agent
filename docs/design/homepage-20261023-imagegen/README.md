# XiaoXi 主页设计方案 · 2026-10-23

本轮使用内置 image_gen 生图工具制作 5 张独立的高保真桌面主页效果图，供用户比较布局和视觉方向。尚未选择实施方案，未修改应用主页。图中的对话、项目、计划和进度均为设计示例，不读取个人数据。
