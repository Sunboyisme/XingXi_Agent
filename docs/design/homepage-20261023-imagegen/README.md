# XiaoXi 主页设计方案 · 2026-10-23

本轮使用内置 image_gen 生图工具制作 5 张独立的高保真桌面主页效果图，供用户比较布局和视觉方向。生图交付时尚未选择实施方案，也未修改应用主页。图中的对话、项目、计划和进度均为设计示例，不读取个人数据。

| 编号 | 方案 | 布局重点 |
| --- | --- | --- |
| 01 | [奶油留白](01-cream-space.png) | 居中问候与输入框，下方轻量日程与上次任务 |
| 02 | [深色专注](02-warm-dark-focus.png) | 暖深色聊天区，右侧独立日程、学习与接续栏 |
| 03 | [双栏工作台](03-split-workbench.png) | 左侧聊天和快捷行动，右侧项目与今日安排 |
| 04 | [晨间手帐](04-morning-journal.png) | 日期与日程主导，底部磨砂输入框 |
| 05 | [轻盈陪伴](05-light-companion.png) | 横向头像问候、开放式快捷入口与接续栏 |

共用特征：保留奶油杏／暖深色品牌语言、双眼圆形头像、图标导航与聊天侧栏、紧凑磨砂玻璃输入框，以及整合附件／MCP／技能的加号入口。各图是生图提案，局部文字、图标、头像渲染及控件密度不作为最终实现规格。

生成提示词和品牌文字修正提示词完整保存在 [prompts.md](prompts.md)。生图阶段未运行应用测试、未打开桌面测试版、未构建安装包。

2026-10-23：用户通过附图选定 **05 · 轻盈陪伴** 并要求开始实现。首轮实现已将横向头像问候、主题光晕、磨砂输入区、五项快捷提示与三项接续栏接入主应用，并同步调整导航文字和侧栏搜索入口。接续栏使用真实计划、学习目标和最近活动项目；无项目时接续最近对话。已完成源码审阅，未运行测试、未打开桌面测试版或构建安装包，待用户验收。具体记录见 [0.1.7 更新记录](../../updata/0.1.7/changes.md)。
