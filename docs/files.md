# 办公文件处理

## 使用

在聊天输入区选择或拖入 DOCX、PDF、XLSX、TXT、MD、CSV、JSON，等待“可读取”或“部分解析”后发送需求。每次最多 4 个附件；办公文件单个最多 20 MB，图片仍为 10 MB。上传和解析状态独立显示，失败可重试或移除，失败附件未处理前不会提交。

小汐使用 `list_files`、`read_file` 按编号读取当前对话的资料，按页码或片段继续读取。结果使用 `create_document`、`create_spreadsheet`、`create_text_file` 生成；可在一个任务里生成多个文件。只有真实产物成功保存后，聊天才提供文件卡片。

生成文件支持 DOCX、PDF、XLSX、TXT、MD、CSV、JSON。DOCX 为基本标题、正文、列表、表格、图片、页眉页脚和分页；PDF 可翻页查看实际渲染页面；Word 为内容预览，完整样式以文件为准；Excel 预览生成时的数值缓存。桌面“下载”直接写入 Windows 下载文件夹，同名文件自动追加序号，不写入应用数据目录，并弹出保存位置与“打开所在文件夹”；“另存为”调用系统保存窗口，用户选择位置，取消不写入文件。浏览器使用标准下载。

## 按本地路径只读访问

无需先上传文件，可以在聊天中直接提供本机绝对路径。例如（将示例替换成实际路径）：

- “读取 `C:\资料\项目报告.docx`，总结重点。”
- “扫描 `D:\工作资料`，包括子文件夹，找出 PDF 文件。”
- “读取 `D:\工作资料\项目 A\说明.md`，列出待办事项。”

建议用反引号或引号包住完整路径，尤其是包含空格、中文的路径。当前聊天提供文件路径后，只能读取该文件；提供目录路径后，可以扫描及读取该目录内的文件。后端只核对当前执行消息及之前的用户原话，其他聊天、助手输出、上传资料和文件中的路径不能扩大范围。路径范围跟随当前聊天，不自动共享到同项目的其他聊天；新聊天需重新提供路径。符号链接、目录联接请提供实际路径，不跟随扫描出来的链接。只支持本机绝对路径，不展开环境变量、相对路径、网络共享、URL、设备路径或备用数据流。

内置工具“读取本地文件”（`read_local_file`）支持 DOCX、PDF、XLSX、CSV、JSON，以及 TXT、Markdown、日志、常见配置和代码等文本；不执行脚本、宏、公式或外部链接。文本支持 UTF-8、带 BOM 的 UTF-16 和 GB18030，单文件最多 20 MB，最多提取 40 万字，单次最多返回 18000 字，按 `next_start` 继续读取；PDF 可指定页码，保留既有 150 页上限和扫描页无 OCR 的限制。PNG、JPEG、WebP、GIF 图片最多 10 MB，使用当前选择的视觉模型提取内容；模型未启用图片输入时明确提示。

内置工具“扫描本地文件夹”（`scan_local_folder`）仅列举名称、路径、大小、修改时间及格式和大小是否支持读取；`readable` 不是权限或解析成功保证。默认扫描当前层并隐藏点号/Windows 隐藏项，可显式包含隐藏项、递归子文件夹和使用 `*.pdf` 等名称通配符。递归最大深度可设 1–10（1 仅当前层），默认 3；结果默认每页 200 项、最多 500 项，按 `next_offset` 继续，偏移最多 5000。单次最多检查 10000 项或约 5 秒，并限制返回内容长度；大目录应缩小范围。达到深度/数量/耗时上限或部分目录无权限时，返回不完整提示，不代表扫描了全部。分页重新读取当前目录，文件变化时结果也可能变化；扫描不跟随符号链接和目录联接。

这两个工具默认启用，可在“连接与设置 → 工具 → 内置工具”中分别关闭。只读取原件，不提供对指定路径的写入、覆盖、创建、删除或移动能力，不把原件自动上传/复制到附件或项目资料库。扫描与读取结果仍会进入本机聊天工具记录，读取的正文/图片会发送给当前选择的模型。已有生成文件工具继续在应用成果区创建新文件，用户仍可自行下载或另存为。

本轮仅做源码审阅及静态语法核对，未运行自动化测试、模拟检查或真实模型调用；实际效果待用户自行验收。后端更新需要重新启动应用才会生效，本轮未代为启动测试版或构建安装包。

## 当前边界

- Word 接受 `.docx`，不接受旧版 `.doc`；不保证保留复杂排版、批注、修订或识别图片中文字。
- PDF 读取有文字层的页面。扫描页明确提示需要 OCR；本轮未实现 OCR。加密文件需要用户先解密。最多解析 150 页、40 万字，截断和缺失有提示。
- 输入 Excel 不执行公式、宏或外部链接。输出支持基础四则运算、SUM、AVERAGE、MIN、MAX、COUNT、ABS、ROUND、单元格及工作表引用；校验循环引用、除零和外部引用。保存时写入计算缓存，Excel 打开后可继续重算。不承诺完整 Excel 函数引擎或复杂模板编辑。
- CSV 为 UTF-8 BOM，处理引号及换行，并将可执行公式样式的文本转为普通文本。JSON 先校验结构。
- 预览按需读取，文本最多展示 100 个片段，表格最多 500 行；下载文件不因预览截断而改变。

## 存储和执行

上传原件以随机编号保存于当前应用数据目录 `attachments/files/*.bin`，和图片附件分开；解析文本与来源保存到 `office_files`。附件随消息绑定对话，工具不能读取其他对话的文件；删除对话后原件及元数据保留，但不再对该对话开放。原件不覆盖，输出保存到现有产物区。便携数据导出/导入已包含新附件目录。

解析、生成和 PDF 渲染使用固定协议的子进程，参数没有任意路径、网络请求或代码执行入口。最多同时 2 个进程，单次 45 秒；Windows 使用进程组和 512 MB 内存上限。输入 ZIP 结构限制解压总量与条目数，并拒绝宏。单个产物最多 20 MB，每轮最多 20 个文件、50 MB；同轮相同请求复用文件。生成失败或取消后不发布半成品。

这是受限的办公文件服务，并非操作系统安全沙箱。现有已授权技能脚本和 MCP 的权限是另外的能力，不会因本文件服务而自动被隔离。用户文件作为资料处理，内容不能授予权限；真正的文件范围由后端校验。读取后的片段会进入当前所选模型的请求，界面会提示。

## 独立图片生成

在「连接与设置 → 连接 → 图片生成」中单独填写图片服务地址、模型和密钥，并启用连接；工具页的「生成图片」也需要保持开启。聊天模型的「图片输入」只代表看图能力，不能替代生图连接。

支持两种同步协议：通用 Images-compatible `POST /images/generations`，以及百炼 Qwen 原生 `POST /api/v1/services/aigc/multimodal-generation/generation`。百炼官方域名（含业务空间专属域名）搭配 `qwen-image` 模型且填写基础地址时，自动选择原生协议；原先填写的 `/compatible-mode/v1` 地址可沿用，程序会调整为同地域、同域名的原生路径。显式填写完整 `/images/generations` 地址则保留兼容协议，不在失败后自动换接口重发。

兼容协议接受 `data[].b64_json` 或 `data[].url`；原生协议按 `input.messages` 发送提示词，并读取 `output.choices[].message.content[].image`。尺寸留空使用服务商默认值；原生协议会把尺寸中的 `x` 转换为 `*`，`auto` 则省略尺寸参数。界面的返回格式只用于兼容协议。协议参考：[OpenAI Images API](https://developers.openai.com/api/reference/resources/images)、[百炼 Qwen 接口](https://www.alibabacloud.com/help/en/model-studio/qwen-image-generation-and-editing-api-reference)。

首版仅支持文字生图，每次一张，不支持参考图片编辑或专有异步任务接口。返回的 Base64 或公开 URL 图片会先校验并保存在本机，单张不超过 10 MB，再使用已有图片预览与下载界面展示。保存配置不会发起付费生成；同轮相同生成请求会复用结果，失败或结果不明确时不会自动重新提交。图片连接配置和密钥不会随数据 ZIP 导出。

本功能本轮未运行测试，运行效果和真实图片模型兼容性由用户自行验收。

配置弹窗提供「测试连接」，使用当前未保存的地址、模型、密钥、尺寸和返回格式；密钥留空时复用已保存的密钥。测试会实际生成并读取 1 张简单测试图，可能产生服务商费用，界面有明确提示。请求和解析过程与 Agent 生图共用，成功时显示图片尺寸、协议和实际接口，失败时显示 HTTP 状态及安全的服务商错误代码。测试不保存配置、密钥、图片文件或聊天记录，修改字段后清除旧测试结果。

生图失败时，回答会根据本轮实际工具记录显示具体原因、图片模型和协议；HTTP 404 等服务错误不会被笼统改写为“Agent 没有图片工具”。

## 验证

- `python scripts/verify-office-files.py`：在 `.local-data/qa-office` 生成七种格式并重新读取，检查中文 PDF 渲染及 Excel 缓存值。
- `pytest backend/tests/test_office.py`：格式、异常、会话范围、重复生成、原件保留、导出，以及模拟模型组合调用生成多文件。
- `BAI_OFFICE_QA=1 BAI_BROWSER_URL=http://127.0.0.1:5196 pnpm exec playwright test tests/browser/office-files.spec.ts`：仅允许隔离目录，验证上传、状态、模型工具链、预览与下载。
- 原生桌面检查复用 `.local-data/preview-runtime`，不得注入模拟文件、消息或替换真实模型连接。真实模型对资料的理解质量及微信收件另行验收。
