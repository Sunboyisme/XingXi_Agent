# 模型用量与费用

在“设置 → 费用”查看今日、近七天、近三十天或自定义日期内的调用，并为连接和模型配置单价。

费用覆盖 XiaoXi 能观察的聊天、学习、复杂任务、上下文压缩、图片理解、Embedding、生图和连接测试请求。第三方 MCP／技能内部自行调用模型时，XiaoXi 无法获得其账单，不纳入统计。

单价由用户填写，默认币种为 CNY。文本与 Embedding 按每百万 Token 计价；生图可以按张、尺寸或实际返回 Token 计价。保存价格只影响后续调用，历史调用保留当时使用的价格快照。不同币种分别汇总，不自动换汇。

服务商未返回完整用量、没有配置价格、请求中断或无法确定是否计费时，显示未知；未知不代表零消费。页面展示的是估算费用，不是服务商实际扣款或余额。仅有总 Token 的旧记录单独保留，不推算输入输出或历史费用。

流式回答、工具多轮、结构修复和可观察的 SDK 重试按实际请求记录；每次请求只入账一次，不与原运行总 Token 重复加计。查询费用和编辑价格不调用模型。流式服务明确拒绝可选用量参数时会兼容降级，无法取得的用量仍显示未知。

本轮未代用户调用真实模型验证账单；各服务商返回格式、缓存计量、图片数量及实际费用仍待用户核对。
