# 本机数据与迁移

打开「设置 → 数据」可查看当前数据目录、记录数量，导出或导入数据。

| 内容 | 实际位置 |
| --- | --- |
| 聊天、思考、摘要、记忆原文与来源、提醒、学习记录 | 数据目录下的 `bai.sqlite` |
| 记忆向量 | 同一 SQLite 文件的 `memory_vectors` 表 |
| 图片与工具/技能产物 | 数据目录下的 `attachments/` |
| 学习流程检查点 | 数据目录下的 `checkpoints.sqlite` |
| API 密钥与微信凭据 | 系统凭据库，按当前数据目录隔离 |

记忆原文在 `memories` 表中，向量只负责语义检索。检索使用中文片段和英文词关键词匹配，加上向量余弦相似度，再通过 RRF 合并排序。未使用 Milvus 或单独的向量数据库服务。

## 导出

点击「导出数据」生成 ZIP，位置显示在页面上。桌面版可点击「打开数据目录」，从 `exports/` 取出文件；浏览器检查环境同时下载 ZIP。

导出包含聊天与历史执行记录、思考、摘要、记忆及其向量、图片、学习记录与流程检查点、提醒与通知、日历计划和工具产物。连接设置、MCP 配置、Skill 技能包及脚本授权、解释器路径、API 密钥、微信绑定、认证令牌与日志不导出。ZIP 未加密，需自行妥善保管。

有任务或索引正在执行时，等待结束再导出；微信连接需要先暂停。当前文件格式支持最多 512 MB 的解压内容，仅导入相同数据库版本的完整导出包。

## 导入

1. 选择 ZIP，检查记录数量和导出时间。此时尚未替换数据。
2. 点击「确认导入，重启后恢复」。也可在重新启动前点击「取消待导入」。
3. 完全退出应用再打开。导入会替换聊天、记忆、向量、图片、学习和提醒，保留本机连接设置与凭据。
4. 系统先把当前数据库、学习检查点及附件备份到 `backups/<时间及编号>/`，再恢复所选数据。页面显示恢复结果与备份位置。

恢复失败会回滚；如果恢复时进程异常退出，下次启动会先恢复备份，再启动后台服务。导入后的向量仍经过当前 Embedding 配置指纹、记忆版本和内容哈希检查；不适用的向量由后台重新索引。

安装版和测试版各自显示自己的目录，操作不会跨目录同步。

0.1.3 的技能包保存在数据目录 skills/ 中，执行工作目录位于 skill-runs/。技能启用、脚本授权及解释器配置属于本机配置，个人数据导入不会替换。可供用户查看的脚本产物复制到 attachments/artifacts/，与执行记录关联并参与数据导出。导入包仍要求与当前数据库结构版本相同；启动时的增量迁移保留已有 0.1.2 本机数据。
