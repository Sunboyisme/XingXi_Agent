# 受限文件操作（0.1.7）

此功能用于读取明确授权的本机资料、整理内容并生成新文件。不包含浏览器、虚拟机、桌面控制或命令执行。

## 使用流程

1. 在聊天输入框的加号菜单选择“受限文件任务”，创建独立会话。
2. 在顶部面板选择文件或文件夹。默认不包含子目录，可勾选递归读取；确认将内容发送给当前模型后授权。
3. 输入整理需求。小夕只能读取授权范围并生成 Word、PDF、Excel、TXT、Markdown、CSV 或 JSON 文件。
4. 在生成文件卡片点击“申请保存”，或由小夕提出保存申请。在顶部面板选择保存位置，再点击“确认新建文件”。
5. 查看实际保存路径和操作记录。目标已存在时更换文件名；原文件不会被覆盖。

不选择资料也可授权仅生成新文件。文件选择器不代表已经授权；保存位置选择器不代表已经保存。

## 权限与数据去向

- 权限仅用于当前受限会话，最长两小时；停止、重启或撤销后需要重新授权。模型服务商、地址或模型名称变化也需重新授权。重新授权可能把本会话已有内容交给新模型。
- 单文件最多 20 MB，图片最多 10 MB；一个会话最多读取 20 个文件版本、累计 100 MB。同一版本分段读取不会重复计数。
- 文件夹授权默认只允许当前层的普通非隐藏文件。拒绝链接、目录联接、硬链接文件、系统与应用凭据范围；不能授权整个磁盘或整个用户目录。
- 读取内容会发送给用户选择的模型。凭据路径拦截不能识别普通文档中所有敏感文字，请只选择希望提供给模型的资料。
- 受限会话不开放联网、脚本、MCP、长期记忆保存或项目历史检索；前端不自动加载外部图片，也不打开模型输出的外部链接。
- 这是一套应用层权限控制，不是操作系统沙箱，也不用于运行不可信代码。普通聊天原有权限不因此改变。
- 当前不支持在生成文档中引用聊天或项目图片，以免绕过本次资料授权。

## 保存与停止

保存只支持本会话生成的文件。确认绑定产物、内容摘要和完整目标路径，十分钟有效，只能执行一次。确认过期、内容变化或任务停止时不可继续执行。

保存时使用临时文件完成写入，然后以不覆盖方式提交到用户选择的位置。Windows 使用目录句柄固定父目录并验证实际路径。失败只清理本次内部临时文件，不删除用户文件。结果不确定时记录“结果待核实”，不自动重试。

“停止并撤销授权”终止后续读取、模型执行和未执行的保存申请。已经完成的文件保留，不会自动撤回或删除。

操作日志保存路径、大小、授权来源和结果，不额外保存文件正文。聊天回答、生成产物仍按原有应用数据规则保存。导出或导入数据不携带活动授权，受限会话标识继续保留。

## 验收方式

权限与故障模拟使用隔离临时数据库。真实模型与原生桌面验收复用 `.local-data/preview-runtime` 的连接和凭据，不向其中导入模拟对话或模拟工具记录。本轮验收结果记录在对应版本更新记录中，模拟、原生窗口与真实模型结果分别列出。
