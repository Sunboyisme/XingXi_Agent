# XiaoXi 0.1.7 更新记录

## 2026-10-23：项目概览、侧栏导航、学习创建与排序按钮（待用户验收）

来源：本版本 `1.png` 至 `6.png` 的反馈、已确认方案，以及“恢复默认排序”按钮位置补充；本节完整同步至 `docs/updata/change.md`。

### 已完成与行为变化

- 日历当天事项：将“恢复时间排序”改为带图标和边框的“恢复默认排序”按钮，与待办／重复标签放在同一行右侧。继续使用原有当天排序恢复接口，恢复当天待办与重复事项的默认顺序；保存期间、加载期间或没有自定义顺序时禁用，不修改事项日期、时间与内容。
- 项目入口：点击项目名进入项目概览，显示项目名称、说明、全部对话、置顶标识、最近更新时间和最近资料；提供新建对话、资料库、上传资料及项目设置入口。资料管理复用原有独立副本、预览、移除及从当前聊天加入的能力，解析中的资料继续刷新状态。
- 对话归属：输入区上方增加项目选择、项目概览与资料库入口。新对话切换项目保留输入文字和附件，首次发送时才创建记录；已有对话选择其他项目会移动当前对话，也可选“未加入项目”。移动期间禁止发送，运行中禁止移动，失败保留原归属；移动成功后同步服务端归属与侧栏，不再用旧项目回退显示。
- 侧栏：将“普通聊天”统一为“对话”，置顶、项目、对话的标题与数量左对齐，工具靠右，滚动区域靠近右边缘。三个分组提供更多、新增与运行状态；工具在悬停、键盘焦点或菜单展开时显示，空闲时不渲染运行图标。置顶新增对话首次发送时自动置顶；对话新增默认未加入项目；项目新增用于创建项目。空分组保留入口，展开状态继续保存。
- 置顶与运行状态：置顶作为快捷入口，不再从项目或未加入项目的完整列表中移除；项目计数包含置顶对话。增加按对话汇总的只读活动接口，用一次轮询派生三个分组的排队／运行数量，侧栏隐藏时停止轮询，不为每个项目单独轮询。
- 任务卡：路由和规划生成最多 40 字的动作与对象短标题，独立于完整任务目标，标题单行省略并可悬停查看。初次规划显示“正在整理任务”，旧记录缺标题时使用已存步骤或“历史任务”，不额外调用模型；展开后可看完整目标。标题保存在现有任务 JSON 中，无数据库迁移。
- 学习创建：聊天工具和学习页共用目标与基础检查，缺少关键信息或只写“基础未知”等占位内容时不保存目标、不启动课程生成。工具返回 `needs_details`，复杂任务转为等待补充，`explicit_request=true` 不再跳过该检查。提示模型从当前对话提取已知目标与背景、集中询问缺项，不从主题或岗位推断用户会编程。
- 入门默认值：学习表单新增明确选择按零基础安排未填写部分的选项；聊天中只有用户明确要求直接安排、从零开始或不想补充时才采用该默认值。保留用户已经提供的具体目标与基础；课程规划与单课生成增加前置知识约束，零基础或基础未知先讲概念、用途和能开始的小练习，避免首课直接要求复杂代码。既有课程及学习进度保留。
- 接口与版本：新增 `/conversations/activity`，保留原项目状态接口；创建对话支持原子保存置顶状态，任务读取增加短标题，学习创建增加入门默认选项，同步前端接口类型。前端、桌面、Rust、后端、关于页和微信客户端版本统一为 0.1.7；依赖版本未升级。

### 静态核对与限制

- 已完成 TypeScript 静态类型检查、10 个相关 Python 文件的 AST 语法解析、差异空白检查，以及异步请求清理、重复操作锁、焦点与草稿保留的源码审阅。接口类型在独立的 schema 导出目录生成，未读取个人预览数据库或调用真实模型。
- 新增缺基础不落库、明确入门选择、直接创建不能绕过信息检查、置顶创建与活动计数隔离的后端回归用例源码；调整原学习确认用例提供完整基础。用例均未执行，静态核对不代表功能或用户验收通过。
- 未运行自动化测试、模拟检查、原生窗口检查、真实模型或微信收件验收；未打开、重启桌面测试版，未构建或运行安装包。后端新增行为须在用户后续要求准备测试版时重启后端才能生效。
- 保留工作区既有版本记录删除、汇总文档删改、反馈图片及其他并行修改；提交仅包含本轮相关差异，不包含个人数据、凭据和安装包。推送继续沿用既有每日定时任务。

2. 点击项目名能看到概览、完整对话与资料；从概览、聊天输入区都能直接打开资料库，上传、预览、移除与解析状态正常。

6. 只提供学习主题时先询问目标与基础，不提前创建目标；已有答案不重复问；信息齐全或明确选择入门默认方案后正常创建，零基础首课从概念和简单实践开始；已有课程与进度不受影响。
