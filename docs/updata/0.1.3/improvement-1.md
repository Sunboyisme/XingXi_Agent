# 0.1.3 改进 1 · 待用户验收

本轮修改运行在固定的 `.local-data/preview-runtime` 桌面测试版。此前的 0.1.3 安装包不包含本轮修改；本轮尚未构建安装包。

## 界面与交互

- 聊天侧栏支持拖动分隔线调整宽度、键盘调宽、双击复位及保存宽度；侧栏与聊天区连续衔接。
- 参考网页默认折叠，重做折叠入口和来源列表。桌面 HTTP/HTTPS 链接通过系统浏览器命令打开；不合法的来源地址不会导致界面崩溃。
- 记忆检索详情移除重复的完整记忆内容，保留来源、检索方式及分数供核对。
- 「日序」改为「日历计划」，统一简洁图标，移除重复外框、底部提示和编辑表单中的冗余文字。月历空白处和周历空白时段支持双击添加。
- 全天计划支持自选当天的提醒时间；保留旧计划默认 09:00，修改后复用同一条关联提醒。完成操作放在已保存计划的操作栏。
- 月历与周历显示农历、节气，保留「节假日 · 休 · 班」图例，包括窄窗口。法定假期和补班采用已核对的 2025、2026 年通知；其他年份不推测调休。
- 技能支持拖入文件夹、ZIP 或文件组，先预览再确认；改善导入按钮文字对比度。说明型技能不显示脚本授权和停止脚本按钮。
- 内置 `text-notes` 首次初始化自动添加并启用，执行脚本仍需单独授权。不覆盖已有同名技能，删除后不反复恢复。
- 设置新增独立的「脚本环境」页面，管理 Python、Node.js、PowerShell、Bash；移除技能页底部的环境管理块。
- 数据库增量迁移 `0009` 仅为日历新增提醒时间，原数据与凭据保留。
