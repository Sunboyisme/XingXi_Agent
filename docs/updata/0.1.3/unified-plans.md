# 统一计划 · 待用户验收

本轮将提醒和日历计划合为一个「计划」模块，保留日历、列表两种视图。铃铛仅管理已触发的通知。此前 0.1.3 安装包不包含本轮改动，本轮没有构建安装包。

数据模型以 `calendar_events` 保存唯一事项，`reminders` 只保存计划的提醒时间和调度游标，`plan_occurrences` 保存某次完成记录，`notifications` 保存触发历史和本次延后时间。支持每天、每周、每月及间隔重复；一个事项最多 10 个提醒时间。

完成本次、结束整个系列、关闭提醒、知道了和稍后提醒分别处理。聊天只暴露统一计划工具，按用户消息和内容去重。旧 API 继续兼容并写入同一个计划服务。导出与恢复包含完整规则及完成历史，本机连接和凭据保持原有策略。

迁移 `0011` 已在隔离样本和真实数据副本预演，复用关联记录，保留状态、提醒时间与通知。真实测试版固定复用 `.local-data/preview-runtime`；自动化测试使用其他目录，不向真实测试版写入测试事项。界面保留之前的农历、节气、休班图例、日期选择器、技能拖入和独立脚本环境设置。

使用说明见[计划](../../calendar.md)。
