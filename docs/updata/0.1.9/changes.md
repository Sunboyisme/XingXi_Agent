## 2026-10-29 · 桌面截图问答、云端语音、手动划词与桌宠（待用户验证）

- 记录来源：用户提供的 9、11、12、13.png，以及本轮讨论后明确要求实施的方案；本节完整同步保存至跨版本汇总。本轮仅实现这四张图对应的桌面功能，保留并行完成的 1–8、10.png 界面及模型参数改动。
- 已修改：新增独立悬浮问答窗口与深色半透明横条，左侧复用支持视线跟随及点击反馈的 XiaoXi IP，占位文字为“随心输入”；加号打开默认定位桌面的原生文件选择器，复用图片/文档上传和解析规则。悬浮区保留自己的会话、模型选择、草稿和附件，回答使用原有运行及流式事件并保存到聊天历史，支持停止、复制、新建和进入主窗口。
- 已修改：短按独立右 Alt 冻结桌面并显示问答横条，横条外显示十字光标与“拖拽截图”；按下左键开始选区并隐藏横条。截图按虚拟桌面的物理像素处理多屏和负坐标，问答横条定位鼠标所在显示器；支持选区移动、八方向调整、尺寸显示、重新框选，以及画笔、直线、箭头、矩形、椭圆、文字、马赛克、线宽、字号、颜色、撤销与重做。工具栏可拖动，包含钉住、提取文字、翻译、复制、PNG 保存、取消及绿色确认；确认只将含标注的图片加入草稿，不自动发送或修改剪贴板。保存取消或失败保留选区，截图时隐藏并恢复桌宠、气泡及已有贴图；贴图支持拖动、滚轮缩放、透明度和关闭。
- 已修改：按住独立右 Alt 达 300 毫秒或点击麦克风开始原生录音；松开右 Alt 或再次点击麦克风结束，显示音量和时长，最长 120 秒。录音转换为单声道 16 kHz、16 位 WAV，识别文字插入原草稿位置，录音/识别期间锁定文字编辑；Esc 取消，失败可在当前会话重试，录音不永久存入附件或数据库。提示统一采用支持悬停与键盘聚焦的 Hint，右 Alt 使用独立键帽底色。
- 已修改：新增硅基流动 SenseVoiceSmall、阿里云百炼 Qwen3-ASR-Flash 和自定义兼容语音接口三套独立连接配置；密钥存入当前数据空间对应的系统凭据库，读取接口仅返回是否已配置。新增 /settings/speech、/speech/transcriptions 和 /speech/calls；兼容迁移 0029 新增语音配置及调用时长/状态记录，原始录音与转写文字不进入语音调用台账，不套用聊天 token 价格，启动时将中断的语音调用标为失败。

- 已修改：新增常驻桌宠，支持拖动、位置保存、跨屏移动、全桌面视线跟随、点击互动与打开问答，右键可进入主窗口、隐藏桌宠或设置。气泡显示运行与完成/失败状态以及已有提醒，可收起并进入对应内容；复用现有提醒轮询，不额外发送重复系统通知，不新增主动闲聊或自主移动。透明区域按鼠标位置穿透，录音、划词与截图异步结果按会话/操作代次过滤；命名互斥量保证同时运行的安装版和测试版只由一个实例持有新增桌面快捷键。
