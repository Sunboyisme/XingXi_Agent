# 0.1.9 修改记录

- 已修改：模型偏好升级为按对话与模型保存，保留旧版模型选择及思考开关读取；切换模型恢复各自设置，新对话首次发送后将草稿参数保存至正式对话。连接配置继续提供默认值，聊天内调整不修改其他对话或全局连接。
