## 数据与边界

- 新增迁移 `0017`，仅增加按创建请求去重的记录表，不改连接、密钥和已有业务记录。此前 `0016` 导出的完整数据包，在暂存副本内经过严格结构匹配后兼容升级；原 ZIP 不变。
- 若新重复规则将移除已有完成记录或单次调整，程序拒绝覆盖，并提示保留重复范围或调整修改范围。旧版已经失联、缺少原始规则的记录不自动猜测恢复。
- 删除清理只覆盖用户实际删除的聊天，不自动扫描或清除旧版遗留的未知文件；本轮没有对个人数据执行删除操作。
- 学习草稿与聊天草稿一样保存在当前应用的本机浏览器存储，不属于便携数据 ZIP；浏览器存储被禁用或空间不足时不能承诺跨页面恢复。
- 新增后端回归用例源码覆盖事务回滚、分批创建、重复记录衔接、通知分页、聊天清理、恢复解析、旧数据包与课程状态；新增学习草稿回归用例源码。本轮均未执行。
