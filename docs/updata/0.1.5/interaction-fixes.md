## 数据与兼容

- 未新增数据库迁移。普通未完成正文保存在现有消息表，单次取消使用现有单次状态表；取消不会计为完成。
- 消息接口补充运行状态和任务归属；重试接口允许可选模型选择。前端接口类型同步更新。
- 未完成正文不进入模型的完成回答或压缩摘要；历史原文仍可检索，并标记为未完成。
- 模型选择保存在本机浏览器存储，不含密钥，也不属于数据导出 ZIP；存储不可用时，本页选择仍可使用，跨页面恢复不作保证。
- 新增后端回归用例源码覆盖未完成正文、当前配置重试、图片正文重置，以及改期事项的取消、提醒排除与恢复；新增前端回归用例源码覆盖发送成功但刷新失败、重试切换会话。已有草稿覆盖和搜索取消用例的预期已同步。本轮均未执行。
