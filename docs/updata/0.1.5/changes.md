## 2026-10-20：首轮更新（待用户自测）

- 按 `1.png` 修正计划编辑时间联动：开始日期或时间晚于结束时间时，结束时间自动跟随；勾选「指定时间」时，新的结束时间为开始时间后 1 小时，跨日时日期同步顺延。

本轮按项目约定未运行自动化测试、模拟检查、真实模型调用或桌面验收，未构建安装包。计划时间联动、粘贴图片、删除确认按钮尺寸和版本显示均待用户自行验证。

## 2026-10-20：MCP 生图结果展示与话术修正（待用户自测）

- 修正工具图片地址识别：MCP 返回在 `results` 等通用数组中的公开图片地址，只要地址路径明确指向图片文件，也会被下载、校验并保存为本轮图片产物，不再只识别 `image_urls`、`image`、`images` 或 Markdown 图片格式。
- 百炼 `bailian_image_gen` 这类返回 `{"results":["https://…png"]}` 的工具结果将直接进入现有图片预览、放大和下载链路。
- 收紧 Agent 执行话术：只有本轮工具结果中的 `artifacts` 非空且没有错误时才能说图片已生成并展示；仅有工具完成状态、`request_id`、文字或远程图片链接不算成功展示。
- 明确区分内置 `generate_image` 未配置与 MCP 生图工具不可用；MCP 已成功调用后，不得再错误回复“所有生图工具不可用”。
- 本轮未运行自动化测试、模拟检查或真实模型调用，未构建安装包；MCP 生图展示、失败回执和后续追问话术待用户自行验收。
